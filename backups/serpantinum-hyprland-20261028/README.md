# Serpantinum + Hyprland keyboard backup

Respaldo del 2026-10-28 de la configuración de Hyprland y los atajos de Serpantinum.

- `hyprland.lua` es el archivo activo que carga Hyprland 0.55+.
- `hyprland.conf` conserva la configuración hyprlang anterior con las mismas combinaciones personalizadas y comandos de Serpantinum.

Para recuperar la configuración Lua, copia `hyprland.lua` a `~/.config/hypr/hyprland.lua` y recarga Hyprland con `hyprctl reload`.
